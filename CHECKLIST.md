## 💡 Pro Tips

- **Start with Hero Section**: This is what visitors see first
- **Real Links Only**: Don't leave `#` placeholder links
- **Test Mobile**: Most people view portfolios on phones
- **Fast Load**: Optimize images before uploading
- **Live Projects**: Prioritize projects with working demos
- **Clean GitHub**: Make sure your GitHub repos are organized

## 🆘 Common Issues

### Build Fails
```bash
# Clear cache and rebuild
rm -rf .next
npm run build
```

### Images Not Loading
- Ensure images are in `public/` folder
- Use paths starting with `/` (e.g., `/projects/image.jpg`)

### Slow Performance
- Optimize/compress images
- Check Lighthouse report
- Minimize animations if needed

### Contact Form Not Working
- See SETUP.md for EmailJS integration
- Or use form services like Formspree
